# Content and asset license inventory

F-Pod ships **no third-party assets**. Every visual, sound and piece of text is generated by code
in this repository or written for it.

| Category | Source | Notes |
|---|---|---|
| Art: tiles, props, characters, icons, chess pieces, card suits, vehicles, UI cards | Vector drawings in `Sources/FPodCore/Presentation/Art/*.swift` | Original; rendered at runtime (CoreGraphics on iOS). |
| App icon `iOS/FPod/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` | Rendered from the in-game icon art by `fpod-tool icon` | Original. |
| Music | Procedural synthesis (`Sources/FPodCore/Audio/Music.swift`: Karplus–Strong guitar, whistle) | Original compositions generated at runtime. |
| Sound effects and character mumbles | Procedural DSP (`Sources/FPodCore/Audio/SFXBank.swift`, `DSP.swift`) | Original; no samples. |
| Text: story, dialogue, documents, item and place names | Written for this project | All characters, institutions and documents are fictional. |
| Fonts | System font (SF Pro Rounded via `UIFont.systemFont(...).withDesign(.rounded)`) | Provided by iOS; not bundled. |
| Chess rules / perft reference positions in tests | Public-domain game rules; standard perft positions | Facts, not copyrighted material. |

## Code

All Swift and Python in this repository was written for the project. It has no package
dependencies: `Package.swift` declares none, and the iOS target compiles only repository sources
and Apple system frameworks (UIKit, SpriteKit, AVFoundation).
